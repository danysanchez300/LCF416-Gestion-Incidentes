# Gestión de Incidentes de Ciberseguridad

## Objetivo

Aplicación académica desarrollada en Python para practicar Programación Orientada a Objetos.

## Clase 7

Este proyecto implementa:

* Asociación entre Usuario e Incidente.
* Dependencia entre GestorIncidentes y Notificador.
* Asignación de responsables.
* Cierre de incidentes.
* Notificación del cierre.
* Control de versiones con Git y GitHub.

## Estructura del proyecto

* `src/main.py`: ejecución del programa y gestión de incidentes.
* `src/modelos/usuario.py`: clase Usuario.
* `src/modelos/incidente.py`: clase Incidente.
* `src/servicios/notificador.py`: clase Notificador.
* `docs/uml_clase7.pdf`: diagrama UML.

## Ejecución

Desde la carpeta principal del proyecto, ejecuta:

```bash
python src/main.py
```

## Datos de prueba

El programa utiliza exclusivamente datos ficticios.
